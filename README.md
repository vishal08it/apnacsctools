# Apna CSC Kendra — Complete Next.js Project (No Python Required)

## Setup & Run (Visual Studio / VS Code)
1. Extract this ZIP file.
2. Open `apna-csc-kendra/.env.local` and paste your free API key from https://www.remove.bg/api (needed only for automatic pure white background removal).
3. Double-click `start-shop-tools.bat` (auto-installs packages including `sharp` and opens http://localhost:3000).

## Open in IDE
- Visual Studio 2022: Double-click `ApnaCscKendra.sln`
- VS Code: Double-click `apna-csc-kendra.code-workspace`

## Kodak 4x6 Print Settings (2 Rows x 4 Portrait Photos)
- Paper Size: 4 x 6 in (or 10 x 15 cm)
- Margins: None
- Scale: 100% / Default
- Media Type: Glossy Photo Paper (Best)
